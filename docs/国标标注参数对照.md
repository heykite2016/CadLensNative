# 国标标注参数对照（渲染基准）

本表是 CadLens 处理尺寸标注时的参照。核心结论先说：**绝大多数参数不需要我们设定**。
DWG 里每个 DIMENSION 都自带一个匿名块，箭头/斜短线、尺寸界线偏移与超出量、文字位置
都是设计师用标注样式（DIMSTYLE）设定后由 AutoCAD 直接"烧"进块里的几何。查看器只要
把块展开，就已经和原图逐像素一致。强行套用下表的数值反而会改坏图纸。

因此下表的作用是三类兜底，而不是覆盖：

1. DIMSTYLE 丢失、或 `DIMTXT = 0` 时，推定标注文字高度；
2. DIMENSION 的匿名块缺失时，合成文字与尺寸线；
3. 判断一幅图偏机械还是偏建筑，决定缺省终端样式（实心箭头 / 45° 斜短线）。

## 参数对照

| 标注维度 | 机械行业（GB/T 4458.4-2003、GB/T 14665-2012） | 建筑行业（GB/T 50001-2017） |
| --- | --- | --- |
| 尺寸线终端 | 实心闭合箭头 2.5 mm，特殊处可用圆点 | 线性标注 45° 斜短线 2~3 mm；直径/半径用实心箭头 |
| 尺寸界线起点偏移 | 0.625 mm | ≥ 2 mm |
| 尺寸界线超出尺寸线 | 1.25 mm | 2~3 mm |
| 基线间距 | 7 mm | 7~10 mm |
| 标注文字高度 | A0/A1 幅面 5 mm；A2/A3/A4 幅面 3.5 mm | 常规 3.5 mm；图名/轴线编号 5~7 mm |
| 文字对齐 | 与尺寸线对齐；角度标注水平注写 | 尺寸数字水平注写；标高数字沿符号方向 |
| 单位 | 默认 mm，不注单位 | 普通尺寸 mm；标高/总平面 m，标高保留 3 位 |
| 图线线宽比 | 粗:细 = 2:1，优先粗线 0.5/0.7 mm | 粗:中粗:中:细 = 4:3:2:1，线宽组 1.4/1.0/0.7/0.5 mm |
| 汉字字高下限 | 3.5 mm，长仿宋，宽高比 0.7 | 3.5 mm，长仿宋/黑体，宽高比 0.7 |
| 特殊符号 | φ、R 前缀；公差带偏差框格 | 标高用等腰直角三角形；索引符号圆 φ8~10 mm |
| 比例系列 | 1:1、2:1、1:2 等 | 1:100、1:50、1:200 等 |
| 图层命名 | 01 粗实线、08 尺寸线等标识号 | 按专业前缀：建筑、结构、给排水等 |

机械另需 GB/T 1182-2018 几何公差；建筑另需定位轴线、剖切符号的专属画法，两者不可混用。

## CadLens 里对应到代码的位置

| 参数 | 来源 | 代码 |
| --- | --- | --- |
| 终端样式、界线偏移/超出、文字位置 | **DWG 自带匿名块**，逐实体展开 | `cadcore.cpp` → `expandBlock()`（DIMENSION 分支） |
| 标注文字高度 | `DIMSTYLE.DIMTXT × DIMSCALE` | `cadcore.cpp` DIMENSION 兜底分支 |
| 高度兜底 | 全图标注文字高度的**中位数**（即 3.5 mm × 出图比例），仅当图中无任何标注文字时用 3.5 | `finishSpace()` 的 `CAD_FLAG_GB_HEIGHT` 处理 |
| 汉字/西文字形 | 内置 `gbenor.shx`（西文）+ `gbcbig.shx`（中文） | `ShxFont.swift`；字高按**实测字冠高**归一化（西文 38 单位、中文 90 单位） |
| 线宽 | 实体 lineweight（mm）→ `0.55 + mm × 1.35` 像素 | `Theme.swift::lineWidth` |

> 出图比例不在文件里显式保存。用"图中标注文字高度的中位数"反推，等价于
> `3.5 mm × 比例`，比任何硬编码常数都可靠。
