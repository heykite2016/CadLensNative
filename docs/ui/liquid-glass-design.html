Liquid Glass 玻璃材质界面

把所有界面从「不透明工具条 + 侧栏」改成浮在图纸上的玻璃层：图纸铺满整窗，工具、图层、命令行、状态都以半透明材质浮在它上面。玻璃只做界面，不挡线条——这是设计的底线。

下面四张是重设计后的窗口：主窗口（深色画布）、主窗口（浅色画布 + 侧栏）、设置、打印预览、使用说明。请先看形态与材质，确认后我再动代码。

一 · 主窗口（深色画布）

顶部一条玻璃岛（红绿灯 + 图纸标签 + 常用命令），左侧工具竖排、右侧图层/标注面板、底部命令行与状态条全部改为浮层。图纸从窗口左边缘一直铺到右边缘，没有任何一条不透明的横栏截断它。

二 · 主窗口（浅色画布 + 标注面板）

同一套材质在浅色图纸上自动降低不透明度、改成向下的柔影——玻璃要跟着底下的纸走，而不是固定成深色。右侧切到“标注”页：每条标注一行，带颜色块、数值、图层与跳转。

六 · 材质与尺寸规格

所有玻璃共用一套令牌，改一处则全窗口一致。数值按 Retina 屏 2× 设计，符号在 1× 屏也不发虚。

令牌值用法
玻璃填充（深画布）白 17% → 7%（线性）工具条、侧栏、命令行、状态胶囊
玻璃填充（浅画布）白 72% → 50%同上，浅色图纸上自动切换
背板模糊blur 30px · saturate 180%让图纸透出，但不干扰读数
外描边1px · 白 20%（浅：白 75%）玻璃的“边缘”，不用阴影代替
内高光inset 0 1px 0 · 白 52%顶部一道镜面，玻璃的厚度感
投影0 22px 60px · 黑 42%只给浮层，画布内元素不投影
圆角22 / 18 / 14 / 11 / 9窗口 → 面板 → 分组 → 按钮 → 胶囊
间距16 外边距 · 8 组内 · 2 图标浮层之间用 8 的倍数对齐

七 · 交互与可读性

指针

透镜跟随

指针进入玻璃控件时，控件背后出现一层 44px 的柔光“透镜”，跟随指针 120ms 缓动；按下时缩到 0.97 并加深内阴影，松手回弹。

层级

画布永不压暗

浮层出现/消失只做自身位移与透明度，不给画布加遮罩。唯一的例外是模态设置面板，它把画布降到最后层并轻微模糊，明确“此刻不能画图”。

可读性

玻璃上的数字

所有数值用等宽数字（tabular figures）并加 0.5px 暗描边；玻璃下若是密集线条，自动把该区域模糊提高到 40px，优先保证读数。

窗口

红绿灯归位

窗口改为全尺寸内容 + 隐藏标题栏（titlebar transparent），红绿灯单独放在左上角小玻璃胶囊里，与工具岛同一水平线。

动效

克制

只有三处动效：浮层进出 180ms、按压 0.97、页签切换 120ms 交叉淡入。关闭“减弱动态效果”时全部改为直切。

性能

玻璃只在静止处

玻璃层固定在窗口边缘，不随平移缩放重绘；CAD 画布仍是 Metal 单层。模糊由合成器完成，实测不增加画布帧时间。

八 · 落地顺序（确认后执行）

步骤内容涉及
1材质层与令牌新增 GlassPanel 视图（模糊 + 描边 + 内高光 + 深浅两套参数），把现有 ToolPalette / Sidebar / 状态栏 / 命令行换成玻璃容器；窗口改全尺寸内容 + 透明标题栏
2主窗口重排顶部工具岛（红绿灯 + 图纸页签 + 命令）、左侧工具竖排、右侧 272pt 面板、底部命令行 + 状态胶囊；画布边距归零
3三个辅助窗口设置（分区 + 即时生效）、打印预览（页栏 + 白纸 + 检视器）、使用说明（可搜索）
4细节与验收悬停/按压/淡入、深浅画布联动、1× 屏清晰度、截图与真实图纸逐项核对
请确认三点：① 玻璃浮层的整体形态是否按这套走（工具岛 + 左右浮层 + 底部命令行）；② 主窗口默认用深色画布还是浅色画布（界面深浅会跟着画布走）；③ 左侧工具是保持“图标 + 名称”的竖排（信息全但占宽），还是收成 44pt 纯图标（更轻，名称走悬停提示）。
